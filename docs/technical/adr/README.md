# Architecture Decision Records (ADRs)

Use one file per decision, e.g. `0001-use-mcp-for-tooling.md`. Copy **[template.md](template.md)** (not published on the site) and fill in sections.

1. **Status** — Proposed / Accepted / Superseded  
2. **Context** — Problem and constraints  
3. **Decision** — What we chose  
4. **Consequences** — Trade-offs and follow-ups
